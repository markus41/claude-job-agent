# Job applications

## Language

**Job**: A specific opening at a target company, carrying observed posting details and an optional fit score.

**Application package**: Candidate materials prepared for one job, including the job details, tailored resume, cover letter and truthful screening answers.

**Armed session**: Time-limited permission to work on one approved application in the browser.

**Batch attestation**: A person's explicit authorization for a bounded number of eligible submissions within a fixed time and score floor.

**Follow-up**: A scheduled reminder and optional draft about an application already submitted; completion records the person's confirmation.

**Workspace readiness**: Whether the candidate's profile, company targets and required setup are usable for a particular stage of the job workflow.
